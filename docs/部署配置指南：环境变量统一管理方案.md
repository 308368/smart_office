# SmartOffice 部署配置指南

## 一、项目概述

本项目为企业智能办公助手，采用前后端分离架构：

- **前端**：Vue 3 + Vite + Element Plus（SPA）
- **后端**：Spring Cloud 微服务（Gateway + Auth + AI + Knowledge + Office + Ticket）
- **部署目标**：Docker 容器化部署至虚拟机

```java
// 原来
@Value("${minio.endpoint:http://192.168.220.100:9000}")
```

#### 3.3.3 `WxLoginController.java` 改造

```java
// 原来
return "redirect:http://localhost:80/login?username=" + username + "&authType=wx";

@Value("${wx.redirect.front-url}")
private String frontUrl;

return "redirect:" + frontUrl + "/login?username=" + username + "&authType=wx";
```

在 `application.yaml` 中添加：
```yaml
wx:
  redirect:
    front-url: ${WX_FRONT_URL:http://localhost}
```

## 四、Dockerfile 编写

### 4.1 后端 Dockerfile

```dockerfile
FROM maven:3.9-eclipse-temurin-17 AS builder
WORKDIR /app

# 复制 pom.xml 和源码

COPY smart-office-common ./smart-office-common
COPY auth-service ./auth-service
COPY ai-service ./ai-service
COPY knowledge-service ./knowledge-service

COPY office-service ./office-service

# 运行阶段

COPY --from=builder /app/smart-office-gateway/target/*.jar app.jar
COPY --from=builder /app/auth-service/target/*.jar auth.jar

```

### 4.2 前端 Dockerfile


## 五、Nginx 配置

### 5.1 `SmartOffice-vue/nginx.conf`（前端项目内）

```nginx
server {
    listen 80;
    server_name localhost;

    root /usr/share/nginx/html;
    index index.html;

    # Vue History 路由模式
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location /assets/ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # API 代理到网关
    location /api/ {
        proxy_pass http://${GATEWAY_HOST:localhost}:${GATEWAY_PORT:8080}/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://${GATEWAY_HOST:localhost}:${GATEWAY_PORT:8080}/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

> 注意：Nginx 配置文件不支持从 `.env` 直接读取变量，需要在 `docker-compose.yml` 中通过环境变量注入或使用 `envsubst` 模板渲染。

## 七、部署流程

### 7.1 开发环境验证

1. 修改 `SmartOffice-vue/.env.development`，配置本地开发地址
2. 修改 `SmartOffice-vue/vite.config.ts`，确保代理指向正确端口
3. 启动后端各服务（直接 `java -jar` 运行）
4. 启动前端 `npm run dev`

### 7.2 生产环境部署

```bash
# 1. 打包前端
cd SmartOffice-vue
npm install
npm run build

# 2. 打包后端
cd ../SmartOffice
mvn clean package -DskipTests

# 3. 上传至虚拟机
scp -r SmartOffice-vue/dist user@192.168.220.200:/path/to/
scp -r SmartOffice/target/*.jar user@192.168.220.200:/path/to/

# 4. 在虚拟机上启动（使用 docker-compose）
docker-compose --env-file .env up -d
```

### 7.3 单体 Jar 打包方案（可选）

如果希望将所有后端服务打包为单个 Jar（需要重构为单模块），可使用 Spring Boot 的分层打包：

```bash
# 在各模块 pom.xml 中启用分层
<configuration>
    <layers.enabled>true</layers.enabled>
</configuration>
```

然后在 Dockerfile 中提取分层依赖，减小镜像体积。

## 九、常见问题

### Q1：微信登录回调地址如何配置？
**A**：微信公众平台后台设置 `authorized_callback_url`，填入 `http://你的域名/api/auth/wxLogin`。后端 `WxLoginController` 的重定向地址也要对应修改为你的前端域名。

### Q2：WebSocket 连接失败？
**A**：检查 Nginx 配置是否包含 WebSocket 升级头，以及 `proxy_set_header Upgrade $http_upgrade` 和 `proxy_set_header Connection "upgrade"`。

### Q3：跨域问题？
**A**：生产环境通过 Nginx 反向代理，前端所有请求发往 `/api/*`，由 Nginx 转发至后端网关，无跨域问题。开发环境通过 `vite.config.ts` 配置代理解决。

### Q4：如何更新配置而不重新构建镜像？
**A**：使用 Docker Volume 挂载配置文件，或将配置放入环境变量，修改 `.env` 后 `docker-compose up -d` 即可。
